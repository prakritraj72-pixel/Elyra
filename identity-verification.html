Identity Verification

ELYRA requires identity verification before a user can participate in bookings. This helps reduce fake profiles and impersonation.

1

Government-issued ID

Complete the secure verification flow using an eligible government identity document. ELYRA does not ask you to send your full ID number through chat.

2

Live face + liveness

You will complete a live selfie/face check. A real-time liveness check is required to reduce photo and replay spoofing.

3

Identity match

The verification provider compares the live face with the identity document and returns the verification result to ELYRA.

Checking verification status…
Privacy: Government ID images and biometric data should be processed by the verification provider. ELYRA stores only the verification result/reference needed to enforce booking access. Never send Aadhaar/PAN images, OTPs or passwords to an Elyra admin by chat.
